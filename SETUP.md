# Setup

This profile is designed for the repository:

`ferhadsultan98/ferhadsultan98`

## Files

Copy these files into the repository without changing their paths:

```text
README.md
assets/hero.svg
.github/workflows/profile-3d.yml
.github/workflows/snake.yml
```

## First run

1. Open **Settings → Actions → General**.
2. Under **Workflow permissions**, enable **Read and write permissions**.
3. Open the **Actions** tab.
4. Run **GitHub-Profile-3D-Contrib** once manually.
5. Run **Generate contribution snake** once manually.

After the first successful run:

- `profile-3d-contrib/` is generated on the main branch.
- the animated snake is published to the `output` branch.
- both workflows refresh automatically every day.

No personal token is required for public contribution data.
